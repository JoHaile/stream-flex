# StreamFlex

A full-stack movie streaming and virtual cinema web application focused on movie discovery and shared watching experiences.

## Overview

StreamFlex is designed around the idea of turning a movie-streaming experience into a shared session. Alongside movie discovery and playback, the project includes virtual cinema functionality where multiple users can join the same viewing session and keep playback synchronized.

## Features

- Movie and TV-series discovery
- Streaming-focused browsing experience
- Virtual cinema rooms
- Shared viewing sessions
- Synchronized playback controls
- Responsive interface for desktop and mobile
- Modern component-based UI

## Tech Stack

- **Framework:** Next.js 16, React 19, TypeScript
- **UI:** Tailwind CSS, shadcn/ui, Base UI, Lucide
- **Data:** Axios
- **Platform:** Vercel-compatible Next.js application
- **Analytics:** Vercel Analytics

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/JoHaile/stream-flex.git
cd stream-flex
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env` file if the application requires external API or service credentials in your environment.

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project Focus

This project demonstrates interactive media UI development, streaming-oriented product design, shared-session experiences, and synchronized client-side interactions using the Next.js ecosystem.
